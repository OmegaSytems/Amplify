# Omega Amplify — OOH and Omnichannel Development

## Reference model
Adapted from the Omega Supply OOH Handbook's objectives, site/catchment selection, permissions, supplier contracts, creative QA, dated installation evidence, in-flight monitoring and removal/close-out requirements.

## Implemented in code
- **28-channel catalogue:** search, social, programmatic, retail media, traditional/broadcast, digital and physical OOH, owned media, partnerships and organic search/publication.
- **20 marketing operations screens:** channel hub; OOH campaign management; placement register; field operations; creative production; media plans; tracking; audiences; tests; lifecycle email; SEO/AEO/GEO; publishing; proposals; onboarding; success; SLAs; suppliers; budget approvals; compliance; integration status.
- **OOH stage gates (demo only):** site permission reference + approved budget + creative reference/approval + service capacity + tracking recorded as tested → supplier booking reference → installation proof → inspection → removal and close-out evidence.
- **Management/staff/client preview navigation:** client views are read-only and scoped to their selected demo account. Production must use actual service entitlement, authentication and per-record server permissions.
- **Sample data** is invented, with no provider access.

## Outstanding engineering
Provider authentication/OAuth, real OOH supplier bookings, actual proof-of-installation uploads, production budget approvals, financial ledger, proper tracking/analytics, email sending and consent records, client contracts/signatures, file storage, actual DNS/URL validation, Supabase Auth and verified RLS, audit trails, regulatory reviews, monitoring, backups, deployment and full browser accessibility testing. These are not complete merely because the demo UI exists.

## OOH safety rules
No physical campaign may be bought or installed without permission where required, budget approval, brand/legal/claims review, feasible fulfilment and verified attribution destination. Outdoor media proof must identify the specific site and date; stop campaigns with unsafe or incorrect placement. No misleading claims, invented inventory rates or fabricated performance. Commercial outreach must meet applicable Australian consent and privacy requirements.
